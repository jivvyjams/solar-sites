# Solar Sites

Full-stack web app where advisors can manage client sites and see estimated solar production and battery self-consumption. Built as a technical assessment project.

## Under Construction

At the moment, this project is a work in progress. Documentation and build instructions are coming soon.

## Tech Stack

### Backend

- Python
- FastAPI
- SQLite

### Frontend

- TypeScript
- React
- React Router
- Tailwind CSS
- Vite
